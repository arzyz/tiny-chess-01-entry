Entry for the [tiny-chess-01](https://make.fun/bounty/tiny-chess-01) competition on [make.fun](https://make.fun).

The strongest chess engine that fits in 4 KB of Python: a deterministic fixed-node negamax search (alpha-beta, quiescence, transposition table, killer-move ordering) with a tapered piece-square-table evaluation plus mobility and passed-pawn terms.
